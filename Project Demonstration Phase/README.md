# Phase 8: Project Demonstration Phase
## Project: Script-Controlled ACL – Restrict Record Access Based on Field Value

### Project Demonstration Overview
This phase contains the visual presentation, demo video links, and execution screenshots of the Script-Controlled ACL implementation.

### Key Features Demonstrated
1. **Dynamic Field Inspection:** Demonstrating access restriction when `Status == 'Confidential'`.
2. **Admin Override:** Demonstrating full system access for Administrator role regardless of field values.
3. **Execution Output:** Console logs showing access approval and denial messages.
